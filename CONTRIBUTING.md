# 🤝 Как внести вклад

1. Сделайте **fork** репозитория.
2. Создайте новую ветку (`git checkout -b feature/НоваяФича`).
3. Сделайте коммит (`git commit -m 'Добавил новую фичу'`).
4. Сделайте **push** (`git push origin feature/НоваяФича`).
5. Откройте **Pull Request**.

Подробнее читайте в [CONTRIBUTING.md](../blob/main/CONTRIBUTING.md).
