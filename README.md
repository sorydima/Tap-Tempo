# 🎵 Tap-Tempo

Лёгкая и быстрая игра на Unity для измерения темпа в BPM (Beats Per Minute) через нажатия!

## 🚀 Быстрый старт

1. Клонируйте репозиторий:
```bash
git clone https://github.com/sorydima/Tap-Tempo.git
```
2. Откройте в Unity Hub (версия 2022.3 LTS).
3. Запустите сцену `MainScene`.

## 🛠️ Стек технологий

- Unity 2022.3 LTS
- C#
- GitHub Actions
